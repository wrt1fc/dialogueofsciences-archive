# Инструкции проекта

Статический HTML/CSS/JavaScript без сборщика и серверной части.

- Данные и переводы находятся в `js/data.js`, поведение — в `js/script.js`.
- Добавляйте работы в общий `ARTICLES` через принятую схему данных.
- Старые работы используют `ARCHIVE_DETAILS` и `ARCHIVE_DOCUMENTS`.
  Не переставляйте существующие записи внутри года: от их порядка зависят ID превью.
- Для материалов разных изданий используйте `collection:true` и `external:true`.
  Не присваивайте им тома журнала или неподтверждённые DOI/EDN.
- PDF лежат в `pdf/ГОД/` и называются `c1.pdf`, `c2.pdf` и далее по порядку
  записей этого года. При добавлении работы используйте следующий номер.
- Проверяйте существование PDF и превью для каждой записи.
- Не имитируйте успешные серверные операции в неподключённых формах.
- Перед завершением запускайте `python -m unittest discover -s tests -v`,
  `node --check js/data.js`, `node --check js/script.js`, `git diff --check`.
- Настройка браузера для тестов описана в README.md.
