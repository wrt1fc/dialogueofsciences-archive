# Горизонты: Диалог наук

Статический сайт с каталогом научных работ за 2021–2026 годы. Основан на
[исходном проекте](https://github.com/Krasilnikov1985/dialogueofsciences.ru).

В каталоге 55 документов: 30 исходных записей за 2024–2026 годы и 25 добавленных
работ за 2021–2023 годы. Все используют общие просмотр PDF, поиск, граф тем,
превью и экспорт цитат. Годовые подборки содержат работы разных изданий;
в архиве они обозначены № 1, без присвоения тома журнала. Названия в списке
переведены на русский и английский, а в экспорте цитат сохранён язык оригинала.

## Запуск

Откройте `index.html` или запустите локальный сервер из корня проекта:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Сборка и установка зависимостей для сайта не нужны.

## Структура

- `index.html` — разделы и окна интерфейса.
- `css/style.css` — темы, адаптивная вёрстка и оформление.
- `js/data.js` — `ISSUES`, `ARTICLES`, метаданные старых работ и словари RU/EN.
- `js/script.js` — отображение каталога, поиск, граф, PDF и цитирование.
- `2021/` … `2026/` — оригинальные PDF; `img/prev/` — первые страницы.
- `files/` — шаблоны рукописей.

Для старых работ добавлены авторы, названия, краткие редакционные описания RU/EN,
число страниц и доступные выходные данные. Названия сохранены на языке оригинала.
Неустановленные реквизиты не выдумываются; полные сведения следует брать из PDF.

## Проверки

Нужны Python 3.10+, Node.js и браузер Chromium:

```sh
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m unittest discover -s tests -v
node --check js/data.js
node --check js/script.js
```

Можно использовать установленный Chrome, задав `CHROME_PATH`. В PowerShell:

```powershell
$env:CHROME_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
python -m unittest discover -s tests -v
```

Тесты проверяют наличие всех PDF и превью, каталог, поиск, цитирование,
переключение языка, уведомления, формы, фокус и ширину страницы на трёх экранах.
Снимки архива сохраняются в `artifacts/`; эталонов для визуального сравнения нет.

## Ограничения макета

Серверная часть отсутствует. Подписка и отправка рукописей не подключены;
интерфейс сообщает об этом и не показывает ложное подтверждение отправки.
Метрики, онлайн, редакционная очередь и сведения о редколлегии взяты из макета
и требуют проверки перед использованием в работающем журнале.
Текущий выпуск 2025 года сохранён согласно исходной редакционной настройке.

Права на исходные материалы и PDF принадлежат их правообладателям.
